# 🧾 AIレシート管理 & 出費ダッシュボード

Gemini API (LLM) を活用し、レシート画像から「店舗名・品目・合計金額・カテゴリ」を自動抽出・分類して視覚的に集計するWebアプリケーションです。

---

## 🌐 動作デモ・URL
- **公開URL**: https://（Renderで発行されたURLを貼る）

---

## 💡 開発背景・目的
手動での家計簿入力の手間を解消するため、レシートをスマホのカメラでその場撮影（または画像アップロード）するだけで、OCR抽出・カテゴリ自動推測・DB保存・グラフ可視化までをシームレスに全自動化するアプリを開発しました。

---

| カテゴリ | 技術スタック |
| :--- | :--- |
| **バックエンド** | Python 3, FastAPI, SQLite, Pydantic |
| **フロントエンド** | HTML5, JavaScript (ES6+ / Fetch API), Chart.js, Bulma (CSS Framework) |

---

## 🌟 主な機能

1. **マルチモーダル入力（画像アップロード＆カメラ撮影）**
   - ファイルのドラッグ＆ドロップおよび、スマホ・Webカメラを起動したその場でのダイレクト撮影に対応。
2. **AI画像解析・カテゴリ自動判定**
   - Gemini APIのマルチモーダル機能を利用し、画像から「店舗名」「購入品目」「合計金額」を抽出。
   - 品目ごとに「食費」「日用品」などのカテゴリを自動判定。
3. **期間別ダッシュボード・集計グラフ**
   - 全期間 / 年別 / 月別 / 週別 での出費集計。
   - 週指定では「選択された日付が含まれる月曜〜日曜」の1週間を動的に計算して自動集計。
   - Chart.js による円グラフ（Doughnut Chart）と内訳割合（%）の表示。
4. **履歴管理**
   - 直近のレシート履歴表示および個別削除機能。

---

## 🔧 工夫した点・技術的アプローチ

- **Structured Outputs（構造化データ出力）の活用**
  - Gemini APIのレスポンスを直接JSONフォーマットで受け取るよう設計し、バックエンド（FastAPI / Pydantic）での型安全なデータ処理とDBへの保存を実現しました。
- **動的な日付計算ロジック（週集計）**
  - 単純な「過去7日間」ではなく、選択した日付を起点としてカレンダー上の「月曜日〜日曜日」の1週間を算出するSQL・Python処理を実装しました。
