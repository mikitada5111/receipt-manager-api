# 🧾 AIレシート管理 & 出費ダッシュボード

Gemini API（LLM）を活用し、レシート画像から「店舗名・品目・合計金額・購入日・カテゴリ」を自動抽出・分類し、データベースへ保存・集計できるWebアプリケーションです。

スマートフォンやPCからレシートを撮影・アップロードするだけで、AIによる画像解析から出費の可視化までを一連の流れで行えます。

---

## 🌐 動作デモ

- **公開URL**: https://receipt-manager-api-4j20.onrender.com
- **GitHub**: https://github.com/mikitada5111/receipt-manager-api

※Gemini APIの無料枠を利用しているため、短時間に多数のリクエストを送信するとレート制限が発生する場合があります。

---

## 💡 開発背景・目的

家計簿をつける際の「レシートを見ながら商品名や金額を手入力する作業」を減らしたいと考え、開発しました。

レシートをスマートフォンのカメラやPCのWebカメラで撮影、または画像をアップロードするだけで、

1. レシート画像をGemini APIで解析
2. 店舗名・購入日・商品・金額を自動抽出
3. 商品ごとのカテゴリをAIが判定
4. データベースへ保存
5. 期間別・カテゴリ別に集計
6. グラフで出費を可視化

という処理を自動化しています。

また、ユーザー認証を導入し、ユーザーごとにレシートデータを管理できる構成にしています。

| **認証** | ユーザー登録・ログイン機能 |
| **インフラ** | Render |
| **ソースコード管理** | Git / GitHub |
